# 📘 **Shiksha-kul — A Smart Classroom Management System**

Shiksha-kul is a web-based smart classroom platform designed to simplify and modernize class management for both **teachers** and **students**.
It integrates **student management**, **assignments**, **attendance**, **tests**, **performance tracking**, and an **AI-powered chatbot**—all within a clean and user-friendly interface.

---

## 🚀 **Features**

### 👨‍🏫 **For Teachers**

* **Student Management**

  * Add, remove, and manage enrolled students
  * Send messages & notifications
  * View student profiles and performance

* **Assignments Management**

  * Create and upload assignments
  * Track submissions
  * Grade and give feedback

* **Attendance System**

  * Smart online attendance
  * Students can mark attendance only once
  * Monthly attendance sheets with alphabetical listing

* **Class Announcements**

  * Post updates & important notices
  * Students receive real-time alerts

* **Test Creator & Manager**

  * Create and publish tests
  * Students can attempt tests online
  * Auto-grading and result storage

---

### 🎓 **For Students**

* View assignments & submit work online
* Attempt tests & view results instantly
* Access class announcements
* Mark attendance online
* Chat with teachers or classmates in 1-to-1 mode
* Ask academic doubts using the **integrated AI chatbot**

---

### 🤖 **AI Chatbot**

* Helps students & teachers with instant solutions
* Built using **Hugging Face API / ChatGPT API**
* Smart doubt solving and contextual responses

## ⚙️ **Setup Instructions**

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/YourUsername/Shiksha-kul.git
cd Shiksha-kul
```

### 2️⃣ Import the Database

* Open **phpMyAdmin**
* Create a new database
* Import the provided `.sql` file

### 3️⃣ Configure Database Connection

Edit `config/db.php`:

```php
$host = "your_host";
$user = "your_username";
$pass = "your_password";
$dbname = "your_database";
```

### 4️⃣ Start the Local Server

Using XAMPP/WAMP:

```
http://localhost/Shiksha-kul
```
